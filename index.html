📲 Installing on Android 13–16? Read this 20-second setup note
  1. Because Saathi uses read-only Accessibility to highlight buttons, Android 13+ locks the switch on sideloaded APKs by default.
  2. Open Settings → Accessibility → Saathi once, then go to Settings → Apps → Saathi → ⋮ (top-right) → Allow restricted settings, and switch Saathi on.
  3. Or install over USB with zero prompts: adb install -r saathi-v0.1.1.apk

3-Tier Edge-to-Cloud Architecture on Google Cloud

Every utterance is answered at the fastest, safest, and lowest-cost tier—routing seamlessly from on-device Kotlin parsers to Vertex AI on Cloud Run.

TIER 1 · ON-DEVICE EDGE (<50 ms · ₹0)

Local Parser & Prepared Guides

LocalCommandParser.kt, tryLocalDomMatch(), and Guides.kt resolve list reads/clears, explicit-time reminders/alarms, exact button lookups, and multi-step WhatsApp flows completely offline.

gemini-3.5-flash-lite

Handles conversational turns, grocery/reminder slot extraction, clarifications, and routine DOM-only screens (Settings, Play Store) with explicit context caching and sub-second speed.

Deterministic Privacy & Safety — Enforced in Code

Unlike raw pixel screen-sharing, Saathi enforces strict boundaries on the phone before a single token reaches the cloud.

Protection Layer How It Works in Saathi's Codebase
Read-Only by Construction canPerformGestures is omitted from XML, and the Gradle auditReadOnly task fails every build if click, gesture, or text-injection APIs appear anywhere in source.
Automatic Bank & Checkout Step-Out Opening strict banking/UPI apps (YONO SBI, HDFC, iMobile, Axis, Kotak, bob World, PNB, GPay, PhonePe, Paytm) or Flipkart/Amazon checkout payment screens speaks a calm reassurance and calls disableSelf() immediately.
WhatsApp Ask-First + ControlsOnly Nothing is read until she says "Haan". Even then, names, chats, timestamps, and typed text become [hidden]—only verified safe button labels leave the phone, and never screenshots.
Multilingual PII & Spoken-Digit Masking PrivacyFilter.kt masks UPI IDs, amounts, emails, and 4+ digit runs—including spoken number words in Hindi, English, and Kannada ("ek do teen char" / "ಒಂದು ಎರಡು ಮೂರು ನಾಲ್ಕು") before network calls.
Zero Raw Logs + Firestore Quotas Cloud Run enforces constant-time secret checks, per-IP burst limits, 200/day per-device & 2,000/day global Firestore caps, store: false, and one-tap "Galat hai / Report" trace flagging to Firestore.
